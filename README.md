# The Museum of Khushi — Romantic Interactive Love Website

A premium romantic vintage virtual museum and interactive love story built with HTML5, CSS3, and Vanilla JavaScript ES6+.

## Running Locally in Visual Studio Code

1. Download or clone this project folder (`love-museum/`).
2. Open the folder in **Visual Studio Code**.
3. Install the **Live Server** extension by Ritwick Dey if you haven't already.
4. Right-click on `index.html` and select **Open with Live Server**.
5. Explore the interactive museum experience seamlessly in your browser!

## Adding Personal Photographs & Audio

- **Memories Photos**: Place your personal `.jpg` files in `assets/images/` named `memory-01.jpg`, `memory-02.jpg`, `memory-03.jpg`, and `puzzle-photo.jpg`. (Fallbacks to Unsplash placeholder imagery are included automatically if images are missing).
- **Background Music**: Place your romantic background track as `background-music.mp3` in `assets/audio/`.
- **Voice Memo**: Place your voice recording of the letter as `love-letter-voice.mp3` in `assets/audio/`.

## Deployment (Netlify or GitHub Pages)

- **Netlify**: Drag and drop the `love-museum` folder directly into your Netlify dashboard for instant deployment.
- **GitHub Pages**: Push the repository to GitHub and enable GitHub Pages in your repository settings pointing to the `main` branch root.
